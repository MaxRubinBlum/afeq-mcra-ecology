# Results directory

Only small, non-sensitive summaries belong here.

Do not commit the complete feature table, complete unpublished metadata, large alignments, QIIME artifacts, or raw sequencing data.

Recommended local outputs include:

```text
mcrA_ASV_master_annotation.tsv
mcrA_phylogenetic_assignments_287.tsv
mcrA_phylogeny_summary.tsv
mcrA_GTR.contree
```

These should normally remain in the analysis workspace rather than GitHub.
